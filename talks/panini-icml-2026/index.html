PANINI: Continual Learning in Token Space via Structured Memory

Structured write-time memory can make read-time reasoning cheaper and more reliable.

Shreyas Rajesh*, Pavan Holur*, Mehmet Yigit Turali, Chenda Duan, Vwani Roychowdhury
University of California, Los Angeles

~20s

Where This Fits: Memory for New Knowledge

LLMs increasingly need to reason over content they were not trained on: new documents, evolving facts, and user-specific information.

Parametric continual learning

Update weights

Can internalize new patterns, but retraining is expensive and risks forgetting or disrupting alignment.

Standard RAG

Retrieve chunks

Keeps the model fixed, but repeatedly asks the LLM to reason over raw passages at inference time.

PANINI

Retrieve chains

Stores structured semantic memory once, then reads compact QA-pair inference chains for each query.

The key shift is from optimizing only read-time retrieval to also asking what should be written into memory.

Write time

Generative Semantic Workspaces

  • Each document becomes an entity- and event-aware graph.
  • Relationships are represented as question-answer pairs.
  • Global memory can consolidate entities, events, and actions across documents.
  • Latent knowledge is represented as inference chains.

PANINI Reads Memory with RICR

Paper Figure 2 embedded from the arXiv PDF. RICR retrieves chains over GSWs and sends compact evidence to the reader LLM.

Read time

Reasoning Inference Chain Retrieval

  • Plan: decompose the query into atomic subquestions.
  • Retrieve: expand candidate paths hop-by-hop through GSW space.
  • Score: keep strong chains and prune weak paths.
  • Answer: provide top chains to the reader LLM.

Why this matters

Non-parametric continual learning should not only retrieve evidence for supported questions. It should also recognize when stored experience does not support an answer.

PANINI improves answerable accuracy while keeping strong refusal behavior.

~45s

Takeaway

Problem

Chunk RAG is a weak memory

It stores verbatim text and repeatedly spends inference compute to rediscover structure.

Solution

GSW + RICR

PANINI writes entity/event-aware QA-pair memories and retrieves reasoning-grounded chains.

Result

Accuracy, efficiency, reliability

Across six QA benchmarks, PANINI improves average performance while using much less answer context.

If RAG asks what to retrieve, PANINI asks what kind of memory should exist before retrieval begins.
